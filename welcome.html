[ SYSTEM LOGIC // HOW IT WORKS ]

Six features.
One unbroken sequence.

Six tools, each one built for a specific moment. No streaks. No shame. No punishment for being human.

[ 01 // INPUT LAYER ]
Say it anywhere
Type it or talk it, messy is fine. Claude files it in the right room, starts a new one, or holds it loose. You never decide where it goes.
Get it out of your head
[ 02 // OBJECT PERMANENCE ]
Rooms
One thing per room, always visible, never lost. Each one opens with where you left off and one small next move. Object permanence, outsourced.
Never restart from zero
[ 03 // THE DAY ]
Build my day
Dump the whole day in one breath. Claude hands back a day you can actually follow, with air between things. Priorities first. Nothing overdue, ever.
A half-full day you can follow
[ 04 // THE PAGE ]
Write about it
A page a day, yours only. The day, the feelings, the stuff with nowhere else to go. Hold what matters, let the rest go.
Nothing to carry to bed
[ 05 // INTERVENTION ]
Feeling stuck
Four doors, then one small move. A dark, quiet screen when everything is everywhere. Never a list. Never a lecture.
Starting beats planning
[ 06 // HUMANS HEAL ]
Real people
Nenemi is the nudge, not the treatment. ADHD coaches, therapists, psychiatrists, and 988, one tap from the stuck screen.
The box holds. People heal.
